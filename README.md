# Nodal Analysis
This project implements Nodal Analysis for oil well performance evaluation using Python. Nodal analysis is a widely used technique in petroleum production engineering to determine the operating point of a well by matching the Inflow Performance Relationship (IPR) with the Vertical Lift Performance (VLP).

## Overview
Nodal analysis evaluates the entire production system by dividing it into components and analyzing pressure–rate relationships. The intersection of the IPR curve and the VLP curve determines the operating point of the well, which represents the stable production rate and bottom-hole flowing pressure.

## Features
- Visualization of IPR curve
- Visualization of VLP curve for different tubing sizes
- Determination of well operating point

## Technologies Used

- Google Colab
- NumPy
